# 📚 Les Nouvelles Voix du 221

> **Les paroles d'hier, la plume d'aujourd'hui.** 🌺

Un site web consacré à la découverte et à la valorisation de la **littérature sénégalaise contemporaine**. Il met en lumière les auteurs, leurs œuvres, les actualités littéraires ainsi qu'un espace de contact, à travers une interface moderne, responsive et interactive.

---

## ✨ Aperçu

Le projet propose une immersion dans l'univers de la littérature sénégalaise grâce à une interface élégante inspirée des bibliothèques modernes.

### Les visiteurs peuvent :

- 📖 Découvrir les auteurs sénégalais contemporains
- 📚 Explorer leurs œuvres majeures
- 📰 Consulter les actualités littéraires
- 📩 Contacter l'équipe du projet
- 🌙 Basculer entre le mode clair et le mode sombre
